# 运乘风水官网前端

纯静态 HTML/CSS/JavaScript 站点。此仓库是官网前端，后端在独立的私有仓库 `yuncheng-server`。`v0.2-beta-freeze` 是 2026-08-26 的冻结标签；当前 `main` 在冻结标签之后继续有维护提交，不能把两者当成同一版本。

## 目录与配置

- `index.html` 等根目录页面：站点页面；`assets/`：样式、图片与浏览器端逻辑。
- `assets/js/config.js`：`YC_API_BASE` 控制浏览器调用的 API 地址；当前文件填写的是 FC 直连地址。修改这个值会影响所有使用该脚本的页面，发布前需核对实际部署环境。
- `tests/test-rotation.js`：户型旋转与落宫一致性检查，不依赖 npm。
- `MP_verify_*.txt`：微信网页授权域名校验文件应与站点根目录一起维护。2026-09-14 移交时，该文件仍只在服务器上，尚未进入本仓库；拿到原文件后核对文件名和线上可访问性，再单独提交。

## 本地检查

```bash
node tests/test-rotation.js
python3 -m http.server 8788
```

第二条在仓库根目录启动静态预览，打开 `http://127.0.0.1:8788/`。本地浏览时 `config.js` 仍指向远程 API；需要纯本地联调时在自己的工作副本中调整配置，结束后核对差异。不要用 `file://` 代替 HTTP 预览。

仓库的 `check.yml` 在推送或提交拉取请求时运行 Node 检查。本地检查只证明现有旋转与落宫逻辑，没有覆盖浏览器全流程、真实 OCR、微信登录、付款或生产部署。
